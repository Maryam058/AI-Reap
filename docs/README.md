# AI-REAP Documentation

- [`requirements/REQUIREMENTS-ANALYSIS.md`](requirements/REQUIREMENTS-ANALYSIS.md) — full breakdown of the source PDF (vision, stack, workflow, roles, all 39 sections) plus open questions/assumptions that need a decision before Phase 1.
- [`requirements/TRACEABILITY-MATRIX.md`](requirements/TRACEABILITY-MATRIX.md) — every requirement assigned a `REAP-xxx` ID, mapped to its PDF section, phase, priority, and build status. Update the Status column as work lands.
- [`roadmap/ROADMAP.md`](roadmap/ROADMAP.md) — phased delivery plan (Phase 0 setup → Phase 1 MVP → Phase 2 AI SDLC → Phase 3 Advanced Intelligence → Phase 4 optional Agentic), each phase ending in a demonstrable increment with explicit exit criteria.
- `architecture/` — reserved for Architecture Decision Records (e.g. the generalized-artifact-data-model decision called out in Phase 0 of the roadmap). Empty until the first ADR is written.

Read order for a newcomer: analysis → traceability matrix → roadmap.
